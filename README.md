A sleek, responsive, and robust task management application built with pure Vanilla JavaScript, HTML5, and CSS3. Features local storage persistence, categorical filtering, priority tags, search capability, subtasks, and delightful micro-interactions.

## ✨ Key Features

- **Full CRUD Operations**: Create, read, update, and delete tasks effortlessly.
- **Priority Levels**: Tag tasks as High, Medium, or Low priority with intuitive color coding.
- **Categories & Filtering**: Organize by Work, Personal, Shopping, or custom tags and filter views instantly (All, Active, Completed).
- **Search Bar**: Real-time searching through your task list.
- **Subtask Support**: Break down complex tasks into manageable sub-checklist items.
- **Persistent Storage**: All tasks securely stored in your browser's `localStorage`.
- **Dark/Light Mode Ready**: Designed with a polished modern dark-accented interface.
- **Zero Dependencies**: Pure web standards with no build step required.

## 🚀 Quickstart & Usage

No installation or compilation needed! Just clone and open.

### 1. Clone the repository
```bash
git clone https://github.com/username/zenith-task-manager.git
cd zenith-task-manager
```

### 2. Run locally
Simply double-click `index.html` or serve it with any static server:
```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx serve
```

Open your browser and navigate to `http://localhost:8080` (or `file:///.../index.html`).
