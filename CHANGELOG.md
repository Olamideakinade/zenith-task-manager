# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v1.0.0/).

## [v1.1.0] - 2025-05-15

### Added
- **Productivity Analytics Dashboard**: View total tasks, completed stats, and efficiency rings in real time.
- **Theme Switcher**: Added Dark and Light mode options with automatic preference detection and persistent storage.
- **Data Backup & Restore**: Export tasks as JSON files and import previous backups easily.
- **Keyboard Shortcuts**: Press `/` to focus search and `Esc` to clear modals or active searches.

### Changed
- Enhanced CSS variables for robust themeability across all components.
- Refactored task rendering pipeline for higher performance and cleaner DOM diffing.
- Upgraded empty states with responsive iconography and helpful guidance.

## [1.0.0] - 2025-01-10

### Added
- Initial release of Zenith Task Manager.
- Core task CRUD operations.
- Category and priority filters.
- LocalStorage persistence.
- Responsive glassmorphic UI design.
